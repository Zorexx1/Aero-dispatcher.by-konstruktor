# Aero-dispatcher.by-konstruktor

Умная диспетчеризация оперативного технического обслуживания (ОТО)

 Описание проекта и его назначение
Прототип информационной системы для диспетчера ОТО ПАО «Аэрофлот». Система автоматизирует процесс назначения техников: при поступлении заявки от экипажа она в реальном времени анализирует координаты агентов на перроне, их квалификацию и занятость. Система предлагает диспетчеру ближайшего доступного сотрудника, гарантируя соблюдение регламента прибытия к воздушному судну (не более 15 минут).

 Состав решения
 `aeroport-by-construktor.py` — основной файл сервера (бэкенд на Flask + WebSocket). Включает в себя алгоритм подбора кандидатов по GPS-координатам, маршрутизацию и логику 2D-симуляции.
 Встроенные в код HTML/JS/CSS шаблоны:
   Интерфейс диспетчера (интерактивная карта, создание заявок, мониторинг).
   Мобильное приложение сотрудника ОТО (прием нарядов, трекинг).
   Автономный 2D-симулятор движения на перроне (Canvas).
Требования к окружению
1) Python 3.8 или выше.
2) Библиотеки: Flask, Flask-SocketIO, Flask-CORS.

 Порядок сборки и запуска
1. Установите необходимые библиотеки командой в терминале:
   `pip install Flask Flask-SocketIO Flask-CORS`
2. Запустите сервер:
   `aeroport-by-construktor.py`
3. Откройте в браузере необходимые интерфейсы:
      Диспетчерская: `http://127.0.0.1:5000/`
       Работник (Мобильный вид): `http://127.0.0.1:5000/employee`
        2D-Симулятор: `http://127.0.0.1:5000/sim`(будет в диспетчерской)

   Использование и тестирование (Сценарии)
Во вкладке «Тесты» интерфейса диспетчера доступны кнопки для проверки алгоритма:
1. Стандартный вызов: Диспетчер создает заявку -> система подбирает инженера -> отправляет наряд -> метка сотрудника едет к ВС.
2. Разброс по перрону: Имитация нахождения сотрудников на рулежных дорожках и в зданиях.
3. Режим аврала: Имитация ситуации, когда все сотрудники заняты (система не дает назначить заявку).
4. Старт из АТБ: Все сотрудники находятся в техцентре, система распределяет логистику оттуда.
